# v0.2.0 — 계산 검증, 자동 전환, 녹음·로그와 듣기 제어

`1+1은 2입니다` 같은 단순 산술은 자료·모델 없이 내장 계산기로 확인합니다. 일반 지식은 `GENERAL_KNOWLEDGE` / 출처 미확인으로 구분하고 화자 누적·해제에서 제외합니다.

- PDF 첨부 시 추출·색인, 페이지·SHA-256 유지, 관련 문단 검색 및 로컬 2,800토큰 상한. Android PDF·음성·추론·저장 작업 큐 분리.
- 자동 / 로컬만 / OpenRouter 우선. 5초 초과 예상 시 선택한 모델로 먼저 전송하고, 로컬 시작 후 5초 초과 시 취소·전환. 경로·사유·시도·시간 표시, 동일 주장에 연결, 늦은 음성 개입 제외.
- Android `Download/meeting-epistemic-gateway/<날짜_회의ID>/`에 전체 마이크 WAV(16kHz·16비트·모노, 1분 분할), 메타데이터·JSONL 기록 자동 저장. 화자 변경·발언 구간 연결, 기록 화면의 재생, 저장 오류 시 일시정지, 미완성 파일 복구. 인증키·실제 회의 파일은 릴리스에 포함하지 않음.
- 웹·APK 듣기 시작/일시정지/재개, 별도 회의 종료·AI 발언 중지. 재개 시 같은 회의의 자료·화자·판정·정책 유지. 배경 이동 시 마이크 중지.
- 저장 형식 v2, v1 읽기, 공통 산술·판정·정책 사례.

**사전 릴리스입니다.** S24 계산은 0–15ms였지만 로컬 1.7B 모델은 일반 지식 예시를 보류했고 자료 검증은 약 14.1초였습니다. 5초 취소·전환, 합성 WAV 분할·재생, 실제 마이크 정지 구간, 저장 오류 주입, 강제 종료 후 복구를 검사했습니다. 실제 OpenRouter 응답속도·결제와 2/4/6인·60분 회의 품질은 검증하지 않았습니다.
